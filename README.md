# DaySync AI

DaySync AI is an adaptive morning planning intelligence that provides a personalized morning plan based on sleep, weather, calendar, and behavior patterns.

## Features
- Dynamic Mode Switching (NORMAL, RUSH, RESCUE)
- Morning DNA (Behavioral insights)
- Calendar & Weather context
- AI-generated morning plan
- Adaptive routine adjustments

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy `.env.example` to `.env` and fill in the values:
   ```bash
   cp .env.example .env
   ```
3. Run the development server (client & backend):
   ```bash
   npm run dev
   ```
